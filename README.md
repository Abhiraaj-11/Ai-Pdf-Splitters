# AI PDF Splitter Pro

AI PDF Splitter Pro is a desktop application for analyzing a PDF with Google Gemini and splitting it into page-level PDF files grouped by detected document sections. It includes a Tkinter GUI and separate command-line tools for compressing, analyzing, and splitting PDFs.

## Features

- Analyze document structure and identify sections with Google Gemini.
- Split the original PDF into individual pages organized into section folders.
- Compress PDFs when needed for AI analysis.
- View processing progress and open the generated output folder from the GUI.
- Run compression, analysis, and splitting as separate command-line steps.

## Requirements

- Python 3.8 or newer.
- Tkinter, included with most standard Python installations. On some Linux distributions, install the system Tk package (for example, `python3-tk`).
- A Google Gemini API key for AI analysis.
- Internet access when sending a PDF for Gemini analysis.

Install the Python dependencies listed in [`requirements.txt`](requirements.txt).

## Setup

### Windows

1. Open PowerShell or Command Prompt in the project directory.
2. Create and activate a virtual environment:

   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt and run `venv\Scripts\activate.bat`, or invoke `venv\Scripts\python.exe` directly.

3. Install dependencies:

   ```powershell
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

### Linux and macOS

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Configure Gemini

Create a `.env` file in the project directory and set your API key:

```env
GEMINI_API_KEY=your_api_key_here
GEMINI_TEMPERATURE=0.1
GEMINI_MAX_TOKENS=8192
```

Get an API key from [Google AI Studio](https://aistudio.google.com/app/apikey). Keep the real key private; `.env` is excluded from Git.

## Run the application

Launch the GUI from the project directory:

```bash
python ai_pdf_splitter_gui.py
```

Alternatively, the repository provides setup-and-launch scripts:

- Windows: `launch.bat`
- Linux/macOS: `./launch.sh`
- Cross-platform Python setup script: `python setup.py`

The launch scripts create/use a `venv`, install the requirements, create a starter `.env` file when needed, and launch the GUI.

## Using the GUI

1. Select a PDF in the application.
2. Start processing. The application validates the file, compresses it for analysis when it is larger than 50 MB, sends the analysis document to Gemini, and splits the original PDF according to the returned sections.
3. Use the output controls to open the generated folder.

The application accepts input PDFs up to 400 MB. The compressed copy is used for AI analysis only; splitting uses the original PDF. A generated analysis file is written next to the selected PDF, and split output is created in a timestamped `output_<timestamp>` directory.

## Command-line tools

Run these commands from the project directory with the virtual environment activated. Replace the example paths with your own files.

### 1. Compress a PDF

Compression is optional. The GUI automatically compresses files above 50 MB for analysis.

```bash
python pdf_compressor.py input.pdf --output input_compressed.pdf --target-size 50
```

The compressor defaults to an output filename ending in `_compressed.pdf` and a target size of 50 MB.

### 2. Analyze a PDF

The PDF supplied to the analyzer must be under 50 MB:

```bash
python ai_processor.py input.pdf
```

By default, analysis is saved as `input_analysis.json` beside the PDF. Choose a different path or enable verbose output with:

```bash
python ai_processor.py input.pdf --output analysis.json --verbose
```

### 3. Split using analysis results

```bash
python pdf_splitter.py input_analysis.json input.pdf --output ./output --verbose
```

The splitter creates a folder named after the source PDF under the requested output directory, with subfolders and individual page PDFs for each detected section. A `splitting_summary.txt` report is also generated.

## Generated files

- `output/` and `output_<timestamp>/`: split PDF files and summary report.
- `<name>_analysis.json`: AI section analysis generated by the GUI or analyzer.
- `<name>_compressed.pdf`: optional intermediate file from the compressor.

These generated outputs are ignored by Git. Other PDFs and JSON files are not globally ignored, so project fixtures and other intentional assets can be tracked.

## Privacy

PDF content submitted for section analysis is sent to Google Gemini using the configured API key. Review Google's applicable service terms and data-handling settings before processing sensitive documents. Compression and PDF splitting are performed locally.

## Troubleshooting

- **Missing Python module:** Activate the virtual environment and reinstall dependencies with `python -m pip install -r requirements.txt`.
- **Tkinter is unavailable:** Install the Tk package provided by your operating system; on many Debian/Ubuntu systems it is `python3-tk`.
- **API key error:** Confirm `.env` exists in the project directory and contains a valid `GEMINI_API_KEY`.
- **PDF is too large for analysis:** Use the GUI (which compresses files larger than 50 MB for analysis) or run `pdf_compressor.py` before `ai_processor.py`.
- **GUI fails to launch:** Confirm Python and Tkinter are installed, then try `python ai_pdf_splitter_gui.py` from the project directory to view the error.
